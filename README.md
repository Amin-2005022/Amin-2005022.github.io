# public_upload

Static file library for sharing PDFs and PowerPoint files.

## Publish with GitHub Pages

1. Create a GitHub repository and push this folder to its default branch.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.
4. Open the URL GitHub displays after deployment.

Add future `.pdf`, `.ppt`, or `.pptx` files to the repository and add a matching link in `index.html`. Each file linked from the page can be opened or downloaded publicly.
